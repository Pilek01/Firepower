# FIREPOWER V0.2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Rebuild the simulator around the new combat version, JSON imports, suppression firepower, and a premium red FIREPOWER interface.

**Architecture:** Keep the combat engine as a testable ES module in `src/simulator-core.js`. The browser UI imports the same API during development, while `src/browser-bundle.js` is regenerated so `index.html` still opens directly from disk.

**Tech Stack:** Static HTML, CSS, JavaScript ES modules, Node built-in test runner, Playwright smoke tests.

---

### Task 1: V0.2 Combat Core

**Files:**
- Modify: `src/simulator-core.js`
- Modify: `test/simulator-core.test.mjs`

**Steps:**
1. Add failing tests for V0.2 base ship stats, JSON key mapping, modifier application, firepower suppression, scan JSON parsing, and report JSON parsing.
2. Run `node --test` and confirm the new tests fail.
3. Replace old ship base stats and implement modifier-based final stats.
4. Implement `calculateFirepower`, `calculateEffectiveShots`, JSON parsers, and V0.2 simulation settings.
5. Run `node --test` and confirm all tests pass.
